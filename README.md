# WeSpark Listening & Speaking UI preview

Desktop-only static UI mockups for discussion. Open index.html or publish this folder with GitHub Pages from the main branch root.

Includes 22 current mockup pages (23 review screens/states), with a shared review toolbar for switching skills, choosing screens and browsing Previous/Next. Superseded Drill prototypes are excluded.

All content/results are illustrative. No authentication, media recording/playback, AI calls, grading, persistence or real student information. Some controls are presentational; native preview state selectors and navigation work. Review order is not a learner completion requirement.

Only the HTML preview bundle belongs here. Do not add briefs, PRDs, evidence, environment files or application source.
